# اختبارات دفتري

اختبارات حقيقية بتشغّل التطبيق نفسه بمتصفح Edge مخفي (headless). الماوس والكيبورد حقيقيين (أحداث المتصفح نفسه، مش محاكاة جافاسكربت)، وكل مجموعة بتشتغل بملف تعريف جديد فاضي. ما في ولا مكتبة خارجية، بيكفي Node.js 20 أو أحدث، وEdge أو Chrome.

## التشغيل عند الطلب

- **بضغطتين:** افتح `tests\run-tests.cmd`. بيشغّل كل الاختبارات، وبآخرها بيفتحلك التقرير.
- **من الطرفية** (من مجلد المشروع):

```bash
node tests/run.mjs
```

- **بس جزء معيّن:** أي كلمة من اسم الملف بتنفع، وبتقدر تعطي أكثر من كلمة:

```bash
node tests/run.mjs ui journey
```

التقرير بيطلع بـ `tests/report/index.html`: عربي، مع صور لكل خطوة مهمة، وصورة تلقائية لكل اختبار فاشل. وفي كمان `report.json` للأدوات. إذا فشل أي اختبار، البرنامج بيطلع بكود 1.

### عن أرقام الأداء

الوقت بيتأثر بضغط الجهاز. لهيك الاختبار بيقيس أول شي «معامل الضغط»: كم بياخذ انتظار 720ms من الإطارات فعلياً. وبيكبّر الميزانية بنفس النسبة، وبيكتب الرقم الحقيقي والميزانية بالتقرير. والتقليب بينقاس على 3 أجزاء: شغل التطبيق قبل الأنيميشن، شغل الستايل والتخطيط، والوقت الكلي.

## الاختبارات بتغطي الإضافات الجديدة لحالها

كتير من الفحوصات بتقرأ من التطبيق نفسه بدل قائمة ثابتة. فلما تضيف ميزة، بتنفحص بدون ما تعدّل الاختبار:

- **الجولة:** كل خطوة بـ `TOURS` لازم يكون إلها عنصر موجود (`04-ui` و`09-system`)، ولازم `TOUR_V` يكون ≥ أعلى `since` (`static`).
- **الأيقونات والأزرار:** كل `ic('...')` لازم تكون موجودة، وكل زر ظاهر لازم يكون إله اسم.
- **قاعدة البيانات:** أي مخزن جديد بينستعمل لازم يكون مضاف بـ `DB.open`، والعكس كمان.
- **التخزين المحلي:** أي مفتاح جديد لازم يكون إله ملف واحد بيملكه.
- **السكربتات:** أي ملف JS جديد لازم ينربط بـ `index.html`، وأي متغير عام لازم يتعرّف مرة وحدة بس.

## كيف تضيف مجموعة اختبارات

مجموعة بدها سيرفر (عامل خدمة، تثبيت)؟ حط `http: true` بالـ`SUITE` والمشغّل بيفتحها من سيرفر محلي، و`T.rpc('server', { on: false })` بيطفّيه (= انقطع النت).

حط ملف جديد بـ `tests/suites/` (مثلاً `13-something.js`). المشغّل بيلاقيه لحاله:

```js
const SUITE = {
  title: 'اسم المجموعة بالتقرير',
  // allowTour: true,   // إذا بدك الجولة تشتغل (عادةً بتنطفي بالاختبارات)
  phases: [
    async T => {
      const { expect } = T;
      await T.test('اسم الاختبار', async () => {
        const b = await T.makeBook('كتاب', { htmls: ['<p>نص</p>', '', '', ''] });
        await Reader.open(b.id, 0); await T.sleep(500); T.quiet();
        await T.mouse.click('#tbInsert');          // ضغطة حقيقية
        await T.waitFor(() => document.querySelector('.pop'));
        expect(document.querySelectorAll('.pop button').length).toBeGreaterThan(3);
        await T.shot('insert-menu');                // صورة بالتقرير
      });
    },
    async T => { /* المرحلة الثانية بتبدأ بعد إعادة تحميل الصفحة: لفحص الحفظ */ },
  ],
};
```

أدوات `T`:

- **اختبار وفحص:** `test`، `expect` (`toBe` `toEqual` `toBeTruthy` `toBeFalsy` `toBeGreaterThan` `toBeLessThan` `toContain` `toHaveLength`)، `waitFor(fn, ms, msg)`.
- **إدخال حقيقي:** `mouse.click(el|selector)`، `mouse.drag(x0, y0, x1, y1)`، `key(key, code, modifiers)`، `typeText(text)`.
- **الشاشة والقياس:** `shot(name)`، `viewport(w, h)`، `metrics()`، `gc()`، `info(obj)` (بيطلع بالتقرير).
- **مساعدات:** `makeBook`، `quiet` (بتطفي الجولة والرسائل)، `clean`، `inView`، `overlap`.

أي خطأ بالكونسول طول المجموعة بيعتبر فشل.
